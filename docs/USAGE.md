## はじめに

YUZU Creator Studio は、ブラウザ 1 枚で画像・動画(音声つき)・音楽・読み上げ・ミュージックビデオ・物語の動画・編集までを行う制作スタジオ。全部 PC の中で動き、外には送らない。ノードをつなぐ必要はなく、タブを選んで素材を落とし、ボタンを押すだけ。

起動は `run.bat`(Linux は `./run.sh`)。ブラウザで **http://127.0.0.1:8700** を開く。止めるときは、起動した画面で `Ctrl+C`。

### 6 つのタブ

| タブ | できること |
|---|---|
| 画像 | 文章から画像を作る(T2I)。参照画像を元に描き直す(edit) |
| 動画 | 文章・最初と最後のフレーム・参照(画像・動画・音声)から、音声つきの動画を作る。静止画も作れる。読み上げの声も作れる |
| 音楽 | ジャンルやテーマ、一言から、歌つき・インストの曲を作る。歌詞は AI が書く |
| MV(ミュージックビデオ) | キャラクター画像 1 枚と曲 1 つから、口の合った MV か、歌わないイメージ MV を作る |
| ショート動画 | 物語の文章・曲・セリフ・参照画像から、物語のある短い動画を作る |
| 編集 | できた動画・画像・曲を、つなぐ・切る・挿入する・色を変える・曲を差し替える(GPU を使わない) |

### エンジン

生成をするのは、裏で動く 4 つの「エンジン」と、管理役が持つ同梱 LLM。

| エンジン | 役目 |
|---|---|
| MiniMax-H3(動画・静止画) | 動画と音声、静止画。MV とショート動画のシーンもこれで作る |
| MiniMax-H3-Image(画像) | 画像タブの画像 |
| ACE-Step(音楽) | 音楽タブの曲 |
| AivisSpeech(音声合成) | 読み上げ(CPU で動く) |
| 同梱 LLM(Gemma 4) | プロンプト強化・作詞・MV の演出・画像を見て人物の説明・曲を聞いて曲の内容 |

エンジンは、使うときに自動で起動し、自動で GPU に載せ替える。自分で起動しなくてよい。

### GPU のメモリの決まりは 1 つだけ

- **VRAM が 40GB 未満の GPU**: GPU に載せるエンジンは **1 つずつ**。画像を作ったあと動画を作ると、画像のエンジンを降ろして動画のエンジンを載せる(数十秒〜数分かかる)。
- **40GB 以上の GPU**: エンジンごとに **利用枠**(使ってよい VRAM の量)を決めて、**同時に複数**を載せる。別のエンジンの生成は並行に走る。

同じタブで続けて作れば、載せ替えは起きない。くわしくは「[エンジンとメモリ](#エンジンとメモリ)」。

### 作ったものはどこに行くか

- できたものは、すべて `outputs/` の下に保存され、画面の **ギャラリー** に並ぶ。
- ギャラリーのものは、どのタブの入力欄にもドラッグ&ドロップで使い回せる。画像タブの画像を MV に、音楽タブの曲をショート動画に、のように。
- ファイルを手元に取り出すときは、生成物の下の **保存**。

この説明は、画面の上の **使い方** を押すと、動かせる窓でも読める(いま開いているタブの節から出る。Esc で閉じる)。

## 画面の見方

![画面(MV タブ。左が操作、右上が生成物とシーン、右下が履歴)](docs/img/screen-mv.png)

### 上の段

- **使用量表示**: 右上に 3 本の棒。
  - **VRAM**: GPU のメモリの使用量(2 秒おきに読む)。棒が 90% を超えると色が変わる。
  - **共有 GPU メモリ**: Windows だけに出る。ここが増えたら、VRAM があふれて CPU メモリに逃げている合図(極端に遅くなる)。
  - **CPU メモリ**: エンジンの分も含めた、PC 全体の使用量。32GB に近づくと、動画の準備や LLM が遅くなる。
- **ジョブの状況**: 使用量表示の下の行。先頭は GPU の使い方(**GPU: エンジン 1 つずつ** か **GPU: 共有(複数のエンジンを同時に載せる)**)。続いて、エンジンごとの実行中の仕事と進み、順番待ちの数(例: `H3: scene 45% / 待ち 1`)。共有のときは、載っているエンジンと利用枠(例: `H3 利用枠 24.0 GiB(仕事中)`)。
- **警告**: VRAM があふれたときや、管理役につながらないときに、帯が出る(「VRAM があふれて共有 GPU メモリに退避しています…」「管理役に接続できません」など)。

### エンジンの欄

タブの上の **エンジン** の見出し。押すと開閉する(エンジンが準備できると自動で閉じ、見出しの横に 1 行で状況が出る)。開くと、エンジンごとの行が並ぶ。

- 名前、状態(**停止** / **起動中** / **準備完了** / **退避中** / **停止中** / **エラー**)、GPU に載っていれば **GPU** の札(共有なら利用枠つき)、外で別に起動していたものには **外部** の札、ポート、使っているメモリ(RSS)。
- ボタン: **起動**(プロセスを起動)/ **停止** / **準備**(GPU に載せて、すぐ使える状態にする)/ **ログ**(そのエンジンの出力を開く)。
- 載せ替えの途中は、行の下にいまの手順が出る。失敗すると「失敗: …」とログの末尾が出る。
- 外部のエンジンと、仕事中のエンジンは **停止** できない。

ふだんは触らなくてよい。生成を押せば、必要なエンジンを管理役が起動・載せ替えする。

### タブの中: 左が操作、右が結果

- **左: 操作**。入力欄と、生成のボタン(**生成** と **中止**、MV は **MV を作る**、ショート動画は **ショート動画を作る**)。
- **右上: 生成物**。いちばん新しいもの(または選んだもの)を大きく出す。下に名前・寸法・長さ・生成時間と、**保存** / **削除** と、タブごとのボタン。進行中のジョブは上に進み(順番待ち・準備中・経過時間)が出る。
- **右下: 履歴**。そのタブで作ったもの。サムネイルを押すと、右上に出る。
  - MV・ショート動画・編集のタブでは、履歴は「制作」「編集プロジェクト」のカードになる。
- 履歴の右上の **ギャラリー** で、右側が **ギャラリー**(すべての生成物、新しい順)に切り替わる。**全て** / **画像** / **動画** / **音楽** で絞り込める。**戻る** で履歴に戻る。
- ギャラリーのサムネイルを押すと、いまのタブの生成物の欄に出る(そのタブのボタンが使える。たとえば動画タブで画像を開くと **最初のフレームに使う**)。

サムネイルの札: **取込** は PC から取り込んだもの、▶ と長さは動画、🎵 と長さは曲。

### 生成物の欄のボタン

| タブ | ボタン | すること |
|---|---|---|
| 画像 | 参照に使う | その画像を、画像タブの参照画像に入れて edit にする |
| 動画 | 最初のフレームに使う | (画像のとき)FL2VA の最初のフレームに入れる |
| 動画 | 参照に使う | Ref2VA の参照に入れる |
| 音楽 | 動画の参照に使う | 曲を、動画タブの Ref2VA の参照(音声)に入れる |

どのタブにも **保存**(ファイルを手元に)と **削除** がある。

### ドラッグ&ドロップ

入力欄には、**PC のファイル** も、**ギャラリーや履歴の生成物** も、同じ操作で落とせる。生成物の欄の画像や、入力欄に入れた素材も、別の欄へドラッグできる。

| 落とす先 | 落とせるもの |
|---|---|
| 画像タブ(操作の欄のどこでも) | 画像。参照画像に入り、作り方が edit になる(最大 16 枚) |
| 動画タブ FL2VA の **最初のフレーム** / **最後のフレーム** | 画像 1 枚ずつ |
| 動画タブ Ref2VA・静止画の **参照** | 画像(9 まで)・動画(3 まで)・音声(3 まで) |
| MV タブの **曲** / **キャラクター画像** | 音声 1 つ / 画像 1 枚 |
| ショート動画タブの **曲** / **参照画像** | 音声 1 つ / 画像 4 枚まで |
| 編集タブの **クリップ** / 挿入の欄 / **音声** の曲の欄 | 動画・画像(まとめて可)/ 動画か画像 1 つ / 音声 1 つ |

- PC のファイルは、落とすとまず取り込まれてギャラリーに入る(札は **取込**)。種類が合わないもの(画像の欄に曲など)は、ギャラリーに保存するだけで欄には入らない。
- 画面の外に落としても、ブラウザがファイルを開いてしまうことはない。

### 削除と「選択」

- 1 件ずつ: サムネイルの **×**、または生成物の欄の **削除**。
- まとめて: 履歴かギャラリーの **選択** を押し、サムネイルを押して ✓ を付け、**削除**。**すべて選択** で見えているもの全部、**やめる** で抜ける。
- 削除はファイルも消え、**元に戻せない**(確認が出る)。
- 消せないもの: 実行中・順番待ちのジョブが使っているもの、MV・ショート動画の制作が使っている曲と画像(完成・中止した制作でも。やり直しや結合し直しに要るため)、編集プロジェクトが使っている動画・画像・曲。断られたら、理由が出る。
- MV・ショート動画の制作を消すときは、確認の窓で **完成した MV も削除する** に印を付けると、完成した動画もいっしょに消える。付けなければギャラリーに残る。

### プリセットの欄

編集以外の各タブの左上。入力欄の値に名前を付けて保存し、選ぶだけで呼び戻せる。

- 選ぶ欄(**プリセット…**)には、**同梱** と **自分のプリセット** が分かれて並ぶ。選ぶと入力欄に入る(生成はしない)。
- ボタン: **保存** / **別名で保存** / **名前の変更** / **削除** / **書き出し** / **読み込み**。名前を聞かれたら欄に入れて **OK**(Enter)、やめるときは **取消**(Esc)。
- くわしくは「[サンプルとプリセット](#サンプルとプリセット)」。

### サンプルのボタン

MV タブとショート動画タブの、プリセットの欄の下にある **サンプル**。同梱の作例を開き、**読み込む** で入力欄と素材を作例のとおりにする(生成はしない)。サンプルの無いタブには出ない。

## 画像タブ

MiniMax-H3-Image で画像を作る。上の 2 つのボタンで作り方を選ぶ。

- **T2I(テキストから)**: プロンプトとサイズを決めて **生成**。
- **edit(参照画像で編集)**: 参照画像を落とし、プロンプトで描き直す。

### プロンプト

- 日本語でも英語でもよい(欄の案内も「作りたい画像を日本語や英語で書きます」)。
- 書く順の目安: 何が(人物・物)→ 見た目(髪・服・色)→ どこで(背景)→ 画風(アニメ調・写真風・水彩)→ 光や構図。
- 画風だけを入れたいときは、同梱のプリセット(**アニメ調イラスト** / **写真風** / **水彩画**)を選ぶと、英語の画風の文が入る。そこに書き足す。
- `Ctrl+Enter` でも生成できる。

### プロンプト強化

**プロンプト強化** を押すと、短い指示を、H3-Image の公式の書き方に沿った詳しいプロンプトに書き直す(同梱 LLM を使う)。

- 書き直したあと、横に **元に戻す** が出る。押すと元の文に戻る。
- 推奨のサイズが返ってきたら、「推奨サイズ: 1024×1024」のように出る。
- edit のときは、参照画像も見て書き直す。
- エンジンと LLM を起こすので、数分かかることがある。

### 画風

**画風**(なし / リアル / 映画 / ドラマ / アニメ / イラスト / スケッチ / 水彩 / 油彩 / 3DCG)を選ぶと、生成のときにプロンプトの後ろへ英語の画風の指示を足す。プロンプトの欄には入れず(欄の下に「画風: アニメ(生成時に指示を足します)」と出る)、プロンプト強化にも入らない。edit では参照画像の見た目を保ち、背景・光・質感を画風に寄せる。足す文は「[動画タブ](#動画タブ)」の表と同じ。プリセットにも入る。

### アングル(edit だけ)

edit のときだけ **アングル** の欄が出る。選ぶと、生成のときにプロンプトの後ろへ英語の指示を足す(欄の下に「アングル: 斜め・左向き(生成時に指示を足します)」と出る)。どのアングルも、最後に「同じ人物(顔・髪・服・画風)、同じ場所・光・背景のまま、ほかの人を足さない」という文が付く。プロンプトが空でも、アングルを選んでいれば生成できる(アングルの文がプロンプトになる)。送る順は **入力欄の文 → アングル → 画風**。プリセットにも入る。

| アングル | 映り方 |
|---|---|
| なし | 足さない |
| 正面 | 目の高さで、まっすぐ正面から |
| 斜め・左向き | 体と顔が絵の **左** 端を向く(右の頬が多く見える) |
| 斜め・右向き | 体と顔が絵の **右** 端を向く(左の頬が多く見える) |
| 真横 | 横顔(90 度横から) |
| 後ろ姿 | 後ろから |
| 見下ろし | 頭の上から見下ろす |
| 見上げ(全身になります) | 床近くから見上げる。全身が入り、上の 2/3 が空や天井になる |

左右は「絵の中で人物がどちらを向くか」で、カメラの回り方ではない。

ヒント: edit はアングルを使わなくても、プロンプトだけで画風の変換や描き足し(アウトペイント)ができる。たとえば「この絵を水彩画に」、「左右に背景を描き足して横長に」(このときは出力サイズを横長にする)。

### サイズ

- 選ぶ欄: **1024×1024** / **1344×768** / **768×1344** / **1536×1536** / **2048×2048** / **自由入力**。横の 2 つの欄に幅と高さを直接入れてもよい。
- **32 の倍数に丸める(256〜4096)**。VRAM が少ないときは小さめに。12GB 前後なら 1024×1024 か 1344×768 が無難。
- SNS 向けの縦長は、同梱のプリセット **縦長 9:16 SNS 用**(768×1344)。

### ステップ数とシード

- **ステップ数**: **サーバ既定** / **2** / **3** / **6**。少ないほど速く粗い。下書きは 2、仕上げは 6(同梱のプリセット **ラフ確認用(2 ステップ)** と **高精細(6 ステップ)**)。
  ステップ数ごとに本体のキャッシュ(約 11GB)を使う。setup が作るのは既定の 3 だけなので、2 や 6 を初めて選ぶと、その 1 回目はキャッシュ作り(62GB のダウンロード、1 時間以上)から始まる。欄の下に「このステップ数は初回だけ本体のキャッシュを作ります…」と出て、ジョブには「本体のキャッシュを作っています(初回だけ)」と出る。先に作るなら、スタジオを止めて `cd <h3image のフォルダ>; .\.venv\Scripts\python.exe scripts\prepare_models.py --build-cache 2 6`(Linux は `.venv/bin/python scripts/prepare_models.py --build-cache 2 6`)。
- **シード**: **ランダム** に印があれば毎回変わる。外して数を入れると、同じプロンプトで同じ絵になる。気に入った構図を保ったまま、文だけ直したいときに固定する。

### edit(参照画像で編集)

1. 参照にしたい画像を、操作の欄のどこかに落とす(ギャラリー・履歴・PC のファイル)。作り方が自動で edit になる。生成物の欄の **参照に使う** でもよい。
2. 参照は最大 16 枚。欄の番号が、プロンプトで指す番号になる(`<Picture 1>` のように書ける)。
3. 「`<Picture 1>` の少女を、夜の街に立たせる」のように書いて **生成**。
4. 参照の × で外せる。

### MV・ショート動画用のキャラクター画像を作る

MV やショート動画では、キャラクター画像 1 枚が **すべてのシーンの元** になる。画像の背景・小物・光は、そのまま全シーンに引き継がれる(窓辺の画像で作ると、5 シーン中 4 つが同じ部屋になった。夜の画像やマイクを持った画像だと、どのシーンも夜・マイクになりやすい)。

1. T2I で、**無地か単色の背景**、**小物なし**、**顔がはっきり見える** 人物を作る。例: 「白い無地の背景。肩までの茶髪、茶色の瞳、白い半袖ブラウスの少女の上半身。正面向き。小物なし。アニメ調」。
2. 正面か 3/4 向きがよい(歌う・話すシーンは口が見える構図になる)。
3. シードを変えて何枚か作り、気に入ったものを選ぶ。
4. その画像を、MV タブの **キャラクター画像** か、ショート動画タブの **参照画像** に落とす。画像タブで作った画像は、プロンプトがそのまま **人物の説明** に入る(空のときだけ)。

場所や雰囲気は、画像ではなく MV の **曲の内容・世界観** や、ショート動画の **物語** に書く。

## 動画タブ

MiniMax-H3 で、音声つきの動画を作る。上の 4 つのボタンで作り方を選ぶ。

| ボタン | 作り方 | 要るもの |
|---|---|---|
| **T2VA** テキストから | 文章から、動画と音声を作る | プロンプト |
| **FL2VA** 最初・最後のフレームから | 最初の画像(と、あれば最後の画像)の間を動かす | 画像 1〜2 枚 |
| **Ref2VA** 参照から | 画像・動画・音声を参照にして作る | 参照 1 つ以上 |
| **T2I / Ref2I** 静止画 | 動画ではなく静止画 1 枚。参照があれば Ref2I、無ければ T2I | プロンプト |

### プロンプト

- 場面・動き・セリフ・音を、日本語か英語で書く。日本語のままでも効く。
- 書く順の目安: 場面 → 人物 → 動き → カメラ → 音 → 終わり方。
- **プロンプト強化** は MiniMax 公式の書き方に沿って書き直す(T2VA / FL2VA / Ref2VA のとき)。静止画では押せない(静止画のプロンプトは画像タブの強化を使う)。**元に戻す** で元の文に戻る。
- セリフをはっきり話させたいときは、文に書くより、下の「音声を作る」で声を作って参照にするほうが確実。

### 画風

画像タブと同じ **画風** の選択。生成のときにプロンプトの後ろへ英語の指示を足す(欄の文は変わらない)。Ref2VA / Ref2I / FL2VA は、参照・フレームの見た目を保つ形の文になる。

| 画風 | 足す指示(英語) |
|---|---|
| なし(参照画像に合わせる) | (足さない。既定) |
| リアル | photorealistic, natural lighting, real camera, true-to-life skin and materials |
| 映画 | cinematic film look, anamorphic framing, shallow depth of field, graded color |
| ドラマ | TV drama look, naturalistic lighting, handheld-feel camera, everyday locations |
| アニメ | Japanese anime style, clean line art, flat cel shading, expressive eyes |
| イラスト | digital illustration, clean shapes, bold colors, polished finish |
| スケッチ | pencil sketch, hand-drawn lines, hatching, paper texture, mostly monochrome |
| 水彩 | watercolor painting, soft bleeding edges, paper texture, muted palette |
| 油彩 | oil painting, visible brush strokes, rich impasto texture |
| 3DCG | 3D CG render, stylized characters, soft global illumination |

参照なしは `Visual style: <指示>.`、参照あり(Ref2VA / Ref2I / FL2VA、画像タブの edit、MV、画像を使うショート動画)は `Keep the referenced subject exactly as in the reference image; render the scene, background, lighting and materials in <指示>.` をプロンプトの後ろに足す。

### 解像度と長さ

- **解像度**: **768×768** / **1344×768** / **768×1344** / **512×512** / **768×512** / **512×768**。ネイティブは短辺 768。6GB のカードは 512²〜768×512 が現実的。
- **長さ**: 5〜15 秒(つまみ)。実際の長さは、コマ数の都合で少し長めに丸まることがある。静止画では出ない。
- **シード**: 画像タブと同じ。**ランダム** を外すと固定。

### FL2VA(最初・最後のフレーム)

- **最初のフレーム(どちらか一方だけでも可)** と **最後のフレーム** に画像を 1 枚ずつ落とす。
- 両方入れると、最初の絵から最後の絵へ動く。片方だけなら、そこから(またはそこへ)動く。
- 画像タブで同じキャラクターの 2 枚を作って入れると、表情や姿勢の変化を作りやすい。

### Ref2VA(参照から)

- 参照の欄に、画像(9 まで)・動画(3 まで)・音声(3 まで)を落とす。**順番に意味がある**。‹ › で入れ替え、× で外す。欄の下に「画像 1/9」のように数が出る。
- プロンプトでは、種類ごとに入れた順で `<Picture 1>` `<Picture 2>` …、`<Video 1>` …、`<Audio 1>` … と指せる(MiniMax-H3 の書き方)。例: 「`<Picture 1>` の女性が `<Audio 1>` の声で、カメラに向かって話す」。
- **音声の長さに合わせる**: 音声がちょうど 1 つのときだけ出る。印を付けると、長さのつまみの代わりに音声の長さで作る。音声から入れ始めると、自動で印が付く。
- **Vocal Lock(参照の音声に口を合わせる)**: 音声が 1 つ以上あるときに出る。印を付けると、参照の音声をそのまま出力の音声にして、口の動きを合わせる。歌や読み上げに口を合わせたいときに使う。
- 同梱のプリセット **歌唱 Ref2VA + Vocal Lock** は、歌う人物の文と、2 つの印が入る。

### 音声を作る(読み上げ)

動画タブの下の **音声を作る(読み上げ)** を開くと、AivisSpeech で文章を読み上げた声を作れる。

1. 読み上げる文を書く(2000 文字まで)。
2. **話者** を選ぶ(開いたときに一覧を読む。AivisSpeech が止まっていれば起動する)。**話速** は 0.5〜2.0。
3. **音声を作る** を押す。できた声はその場で聞け、ギャラリー(動画タブの履歴)に入る。
4. 作り方が Ref2VA のときは、作った声が自動で参照に入る(「音声を作って、参照に加えました」)。

選んだ話者は覚えておき、ショート動画タブの話者にも引き継ぐ。

### よく使う組み合わせ

- **キャラクターに話させる**: Ref2VA に、キャラクター画像と、読み上げの声を入れる → **音声の長さに合わせる** と **Vocal Lock** に印 → 「`<Picture 1>` の人物が、カメラに向かって静かに話す」。
- **曲に合わせて歌わせる**: 音楽タブの曲の **動画の参照に使う** → キャラクター画像も入れる → 同梱のプリセット **歌唱 Ref2VA + Vocal Lock**。15 秒より長い曲を通して歌わせるなら MV タブを使う。
- **静止画を動かす**: FL2VA の最初のフレームに画像を入れ、動きだけを書く。

### VRAM と時間の目安

- 動画は turbo LoRA の 4 ステップで作るので、入門機でも待てる時間に収まる。それでも画像より時間がかかり、解像度と長さに比例して増える。
- 初めて動画を作るときと、画像・音楽のタブから来たときは、エンジンの載せ替えで数十秒〜数分余分にかかる。
- 時間がかかりすぎる、または上に「VRAM があふれて…」と出たら、解像度を 512×512 や 768×512 に下げる。

## 音楽タブ

ACE-Step で曲を作る。先頭の **作り方** で 2 つから選ぶ。

- **簡単(ジャンルから)**: ジャンルを選び、テーマ・歌詞・キャプションは書いても書かなくてもよい。**空の欄だけ** を、生成のときに AI が作る(書いたものは作り直さない)。
- **✨ おまかせ(一言から)**: **どんな曲?** の欄に「雨の夜に聴く切ないバラード」のような一言を書くだけ。ACE-Step の LM が、キャプション・歌詞・BPM・調まで決める(管理役の LLM は使わない)。

### ジャンル(簡単のとき)

- 同梱のチップ 12 個: J-POP / Rock / Ballad / Anime / Hip Hop / R&B / Enka / EDM / Reggaeton / K-POP / City Pop / Jazz。1 つ選ぶ。
- **＋ 追加**: 自分のジャンルを作る。名前(例: 和風エレクトロ)と、任意の一言の説明を入れて **追加**。AI が世界観・場面・感情の定義を作り(CPU では 10〜60 秒)、✦ 付きのチップになる。
- ✦ のチップを選ぶと、下に **ジャンルの中身** が出る。名前・世界観・場面・感情・スペクトラムの雰囲気を直して **保存**、または **削除**。保存すると、次の曲から使われる。
- **✎ 自由に書く**: チップの代わりに文で書く(200 文字まで)。例: 「90 年代のシティポップに三味線を混ぜた、夏の終わりの切ない曲」。テーマ・歌詞・キャプションを作るときも、この文を使う。**ジャンルとして保存** で、短い名前を付けて ✦ のチップにできる。

### 共通の欄

- **歌の言語**: 日本語 / English / 中文 / 한국어 / Español / Français / Deutsch / Italiano / Português / Русский。
- **曲長**: **自動** / 30 秒 / 60 秒 / 90 秒 / 120 秒 / 180 秒 / 240 秒。MV に使うなら、まず 30〜60 秒で試すと早い。
- **楽器のみ(歌なし)**: インストにする。歌詞とボーカルの欄は使わなくなる。

### テーマ・歌詞・キャプション(簡単のとき)

| 欄 | 中身 | AI のボタン |
|---|---|---|
| テーマ / シナリオ | 曲の題材(例: 夜行バスの窓から見える朝焼け)。曲名にもなる | **✨ テーマを作る** |
| 歌詞 | `[Verse]` `[Chorus]` などのタグが使える | **✍️ 作詞する**(テーマが空なら、テーマも作る) |
| キャプション | 音の説明(英語) | **🎵 キャプションを作る** |

- 3 つのボタンで、生成の前に 1 つずつ作って直せる。各欄の ✕ で消せる。
- 作詞すると、「AI の推奨の長さ: 約 N 秒」が出る。曲長の目安にする。
- **キャプション自動(空なら生成時に AI が作る)**: 既定でオン。
- 自分で書いたキャプションは、AI が作るテーマ・歌詞の雰囲気の参考にもなる。
- **ムード**(😊 明るい / 😢 切ない / 🔥 激しい / 🍃 穏やか / ✨ 神秘的 / 💕 ロマンチック / 🎉 楽しい / 🌙 メランコリック / 🏔️ 壮大 / 😎 クール)と **ボーカル**(👩 女性 / 👨 男性 / 🎤 力強い / 🌬️ ウィスパー / 🎵 ファルセット / 👥 ハーモニー)は任意。もう一度押すと外れる。

### 生成と「歌詞を新しくして生成」

- **生成** を押すと、作ったプラン(テーマ・キャプション・歌詞の先頭)が下の **曲のプラン** に出る。AI が作った分は、欄にも残る(次はそれを使うか、直して使う)。
- **✍️ 歌詞を新しくして生成**(歌詞があるときだけ出る): 歌詞を消し、テーマはそのままで、歌詞とキャプションを作り直して生成する。

### 詳細(閉じてある)

| 欄 | 意味 |
|---|---|
| モデル | ACE の一覧から。未読込のものは、生成の前に自動で読み込む(数十秒)。VRAM に載らないものは選べない |
| STEP | **8 (Turbo)** / **20 (高速)** / **50 (標準)** / **80 (高品質)** / **100 (最高品質)**。モデルを選ぶと自動で合う(Turbo 8、それ以外 50) |
| 曲数 | **1 曲** / **2 曲** / **4 曲**。2 曲以上は別々の生成物になる(SFT のモデルは 2 曲まで) |
| Thinking(ACE-Step の LM で高品質に作る) | 既定でオン |
| シード | **ランダム** か固定。**同じ骨格で作り直す(前回のシードを使う)** で、歌詞やキャプションだけ変えて同じ骨格の曲にできる |
| ネガティブプロンプト | 避けたい音(英語)。既定の文が入っている |
| Shift | **自動** / 1.0 (ディテール重視)〜 5.0 (最大)。低いと音質重視、高いと構造重視 |
| Sampler | **自動 (ODE)** / **ODE (安定・クリーン)** / **SDE (有機的・多様)** |

### スペクトラム

曲を再生すると、生成物の欄の曲のカードで光の表示が動く。カード右上の選ぶ欄で、スペクトラム / 波形 / リング / 粒子 / 脈動 / オーロラ / 花火 / マトリックス / 軌道 / 炎 / おまかせ を切り替えられる(選んだものは覚えておく)。色合いは、自作のジャンルの雰囲気、無ければムード、それも無ければキャプションの言葉、それも無ければジャンルで決まる。カードの **歌詞** を開くと全文が見られる。

### 曲を他のタブで使う

- **MV**: 曲を MV タブの **曲** に落とす。テーマ・キャプション・ジャンルが **曲の内容・世界観** に入る(空のときだけ)。
- **ショート動画**: **曲** に落とすと BGM になる(セリフが無ければ、曲の長さが動画の長さ)。
- **動画**: 生成物の欄の **動画の参照に使う** で、Ref2VA の音声の参照になる。
- **編集**: **音声** の曲の欄に落とすと、曲の差し替えに使える。

## MV(ミュージックビデオ)タブ

キャラクター画像 1 枚と曲 1 つから、MV を作る。曲を 5〜10 秒のシーンに分け、シーンごとに MiniMax-H3 で動画を作り、最後に元の曲をつける。音声の分離の道具が要る(setup が既定で入れる)。無ければタブの上に案内と **道具を入れる(約 1.3GB)** ボタンが出て、入れ終わるまで **MV を作る** が押せない。

Windows と RAM 48GB 未満の PC では、MiniMax-H3 の参照モード用のキャッシュ(transformer_ref_int8、約 32GB)も要る(MV のシーンは全部 Ref2VA で作るため)。無ければタブの上に、この PC 用の作るコマンドつきの案内が出て、**MV を作る** が押せない。作り方は「[困ったとき](#困ったとき)」の「参照モード用のキャッシュがありません」。

### 入力

- **曲**: 音楽タブの曲・ギャラリー・PC の音声ファイル。欄で聞ける。× で外す。
- **キャラクター画像**: 画像タブの画像・ギャラリー・PC の画像ファイル。画像の選び方は「[画像タブ](#画像タブ)」の最後を参照。
- **人物の説明**(任意): 髪・目・服・画風など、見た目だけを書く。空なら画像のプロンプト、それも無ければ画像を見て作る。
  - 画像タブで作った画像を落とすと、そのプロンプトが入る(空のときだけ)。
  - **🔍 画像から作る**: 同梱 LLM が画像を見て、見た目(誰・顔・髪・服・画風)を日本語 1 行にする。場所・光・ポーズは入れない。CPU で 10〜60 秒ほど(初回は、画像・音声を読む投影ファイル 約 0.56GB を取得する)。
- **曲の内容・世界観**(任意): 曲の題材や、映像にしたい世界。空なら曲のテーマ・キャプション・ジャンル、それも無ければ曲を聞いて作る。
  - 音楽タブの曲を落とすと、テーマ・キャプション・ジャンルが入る(空のときだけ)。
  - **🎧 曲から作る**: 同梱 LLM が曲の 30 秒を最大 2 か所聞き、言語・ジャンル・雰囲気・楽器・ボーカル・テンポを読み取って、曲の内容・世界観の案を書く。CPU で 20〜60 秒ほど。音楽タブの曲は、聞かずにテーマ・キャプションから書く。歌詞は聞き取らない。
  - 聞き取った中身は、欄の下の **曲の聞き取り(参考)** に閉じて出る(聞き間違えることがある)。
- 自動で入った文は、確かめて直してから作れる。自分で書いた文は、確認なしには置き換えない。
- 外から持ち込んだ画像・曲で欄が空なら、「空のまま作ると、自動で入れます」と出る。そのまま **MV を作る** を押しても、制作の中で同じことを自動でやる。

### 歌わせ方

- **歌わせる(リップシンク MV)**: シーンごとに、分離したボーカルを H3 に渡し、口を合わせる(Vocal Lock)。歌の無い区間(間奏など)は口を閉じる。
- **歌わせない(イメージ MV)**: ボーカルを渡さず、画像だけを参照に作る。キャラクターは歌わない。歩く・見つめる・景色など、どんな構図でも使う。曲は結合で付く。

歌わせないでも、演出を書く LLM が「MV」からマイクやステージを選ぶことがある(口は動かないが、マイクを持つシーンが出た)。景色や日常だけにしたいときは、**曲の内容・世界観** に出したくないものを書く。

```
夜明けの駅で、旅立つ人を見送る歌。マイクやステージは出さない。歌う場面は無い。
```

この文は、そのまま演出の LLM に渡る。歌わせないを選ぶと、欄の下にも同じ案内が出る。

### 画角と画質

- **画角**: **横長 16:9** / **縦長 9:16** / **正方形 1:1** / **縦 4:5** / **横 4:5** / **手動入力**。
- **画質**: **低 VRAM** / **高速** / **標準** / **高画質**。画質の横に、実際の寸法が出る。

| 画角 | 低 VRAM | 高速 | 標準 | 高画質 |
|---|---|---|---|---|
| 横長 16:9 | 512×288 | 768×448 | 1024×576 | 1344×768 |
| 縦長 9:16 | 288×512 | 448×768 | 576×1024 | 768×1344 |
| 正方形 1:1 | 384×384 | 512×512 | 768×768 | 960×960 |
| 縦 4:5 | 416×512 | 512×640 | 640×800 | 768×960 |
| 横 4:5 | 512×416 | 640×512 | 800×640 | 960×768 |

| 画質 | 向いている GPU |
|---|---|
| 低 VRAM | 6GB 以下。長辺 512 の小さな画。まず速く試したいときにも |
| 高速 | 6〜12GB。いちばん速い |
| 標準 | 16GB 以上 |
| 高画質 | 24GB 以上。時間がかかる |

- 既定の画質は、VRAM が 16GB 以上なら標準、未満なら高速。
- **手動入力**: **幅(px)** と **高さ(px)** を直接入れる(256〜1344、32 の倍数に丸める)。画質の欄は使わない。
- 同梱のプリセットに、YouTube・TikTok・Instagram 向けの画角と画質の組み合わせがある。

### 画風

**画風** を選ぶと、演出を書く LLM に「全シーンをこの画風に」と指示し、各シーンの最終のプロンプトの画風の文(既定は cinematic music-video style)をその画風の文に替える。キャラクターの見た目は画像のまま保つ。なしなら従来どおり。

### そのほかの欄

- **背景の文字**: 看板や画面に描く文字。**おまかせ** / **大きな文字だけ** / **文字を出さない**。動画は大きく短い文字なら描けるが、小さな文章は崩れがち。字幕・テロップ・歌詞の文字・タイトル・ロゴは、どれを選んでも出さない。
- **シーンの最短(秒)** / **シーンの最長(秒)**: 5〜10 秒(最短は最長以下)。短めにするとカットが増えてテンポが上がり、シーンの数(=時間)も増える。縦長のショート向けなら 5〜7 秒。
- **シード**: 固定すると、同じ入力で同じ MV に近くなる。

### 作る

1. 曲とキャラクター画像を落とす。
2. 人物の説明と曲の内容を確かめる(空でもよい)。
3. 歌わせ方・画角・画質を選ぶ。
4. **MV を作る**。右上に制作の画面が出る。

### 中で進む順番

| 段 | 何をするか | 使うもの |
|---|---|---|
| 分離と分割 | ボーカルを分け、無音・息継ぎ・小節から 5〜10 秒のシーンに分ける | CPU(Demucs) |
| 曲を聞く | 曲の内容が空で、曲に手がかりが無いときだけ。曲を聞いて曲の内容を作る | 同梱 LLM(CPU) |
| 演出 | 人物の見た目を整理し、シーンごとの演出を書く。歌う区間は口が見える構図にする | 同梱 LLM |
| シーンの生成 | シーンごとに Ref2VA(歌わせるなら Vocal Lock も)で動画を作る | MiniMax-H3(GPU) |
| 結合 | クリップをつなぎ、音声を元の曲に差し替えた MP4 にする | CPU(ffmpeg) |

- 1 シーン終わるごとに次を入れるので、その間に他のタブの生成が割り込める。
- 曲を聞けなくても止まらず、曲の内容なしで進む。

### 制作の画面(右上)

- 題・状態(**分析中** / **演出を作成中** / **シーンを生成中** / **結合中** / **一時停止** / **完成** / **失敗** / **中止**)・進み・寸法・シーン数・曲の長さと BPM・経過時間。
- 自動で入れた説明があれば、どれが自動か(「画像を見て自動で作りました」「曲を聞いて自動で作りました」など)が出る。
- ボタン: **一時停止**(走っている仕事は終わるまで続け、順番待ちは取り下げる)/ **再開**(できているところから続ける)/ **中止**(あとで再開できる)/ **結合し直す** / **削除**。
- 完成すると、最終の動画と **保存** が出る。
- 管理役を再起動しても、途中の制作は一時停止として残る。**再開** で続きから進む。

### シーンごとのやり直し

各シーンの行に、時刻・長さ・**歌唱** か **器楽** の札・状態(**待機** / **生成中** / **完了** / **失敗**)・seed・生成時間・VRAM の山が出る。

- **やり直す**: 別の seed で作り直す。
- **プロンプトを編集**: H3 に渡す演出の文と seed を直し、**この内容でやり直す**。**閉じる** でやめる。
- 全シーンがそろうと、自動で結合し直す。前の MV はギャラリーに残る。
- **結合し直す**: いまのクリップをつなぎ直して、新しい MV を作る。結合し直す前の動画には「古い版です。結合し直すと更新されます」と出る。

### うまく作るこつ

- **キャラクター画像は無地の背景・小物なし**。背景・小物・光は全シーンに入り込む。
- 場所や雰囲気は **曲の内容・世界観** に書く(「海辺の町、夏の夕方、自転車」など)。
- 出したくないもの(マイク・ステージ・字幕など)は、はっきり書く。
- 初めは **高速** か **低 VRAM** で 30 秒の曲を作り、よければ画質を上げる。
- 気に入らないシーンだけ **やり直す**。全部を作り直すより早い。

### 時間の目安

| GPU | 条件 | 時間 |
|---|---|---|
| RTX A4000(16GB) | 横長・高速、30 秒の曲(5 シーン) | 約 17 分(1 シーン約 3〜3.5 分) |

曲が長いほど比例して増える(3 分の曲なら約 1 時間 40 分)。標準・高画質はさらにかかる。大きな GPU(RTX PRO 6000 や 5090)では、その数分の 1。

## ショート動画タブ

物語の文章から、物語のある短い動画を作る。仕組みは MV タブと同じ(準備 → 演出 → シーンごとの生成 → 結合)で、MiniMax-H3 だけを使う。曲だけの動画は MV と同じ音声の分離を使うので、そのときだけ同じ道具が要る(setup が既定で入れる。無ければ **道具を入れる** ボタンが出る)。

### 時間軸は 3 通り

何を入れたかで、動画の長さとシーンの切り方が決まる。

| 入力 | 長さ | シーンの切り方 | シーンの音 |
|---|---|---|---|
| セリフあり + 人物の画像(曲は任意) | 読み上げの長さ | 文の切れ目で 5〜10 秒にまとめる | 人物が読み上げに口を合わせる。曲は BGM として下に敷く |
| セリフあり、人物の画像なし(ナレーション) | 読み上げの長さ | 同じ | 画面の外の声。景色のシーンを音なしで作り、結合で読み上げ(+ 曲を BGM)を載せる |
| 曲だけ | 曲の長さ | MV と同じ(ボーカルを分け、無音・息継ぎ・小節で切る) | 音声を渡さずに作り、結合で曲に差し替える |
| どちらも無し | 指定した長さ | LLM が物語から 5〜10 秒のシーンに割る | H3 が作る音(環境音・効果音)をそのまま残す |

入力に合わせて、長さの欄の出し入れと案内(「長さ: 曲の長さ(1:30)」など)が自動で変わる。

### 入力

- **物語・映像のイメージ**: 何を描くか。曲もセリフも無いときは必須(案内が「必須: 曲もセリフも無いので、これが元になります」になる)。あれば任意。
- **曲**(任意): 音楽タブの曲・ギャラリー・PC の音声ファイル。セリフがあれば「セリフがあるので、曲は BGM として下に敷きます」と出る。
- **セリフ・ナレーション**(任意): あれば AivisSpeech で読み上げる。人物の画像があれば人物がそれに口を合わせ、無ければ画面の外の声(ナレーション)として景色に載せる。空のままなら、セリフなしの動画になる。
  - **📝 物語から作る**: 物語の文章から、同梱 LLM がナレーションの案を書く(曲があれば、その内容も使う)。CPU で 20〜60 秒ほど。確かめて直してから作る。
- **話者**: セリフがあるときは必須。セリフを入れると一覧を読む(AivisSpeech が止まっていれば起動する)。動画タブの読み上げで選んだ話者を引き継ぐ。
- **セリフのテロップ(字幕)を焼き込む**: 読み上げの文の時刻どおりに、画面の下(縦長は少し上)に白い字のテロップを焼き込む。同じ内容の SRT も、最終の動画の隣に保存する(投稿サイトの字幕用)。セリフの無い制作では何もしない。
- **参照画像**(0〜4 枚): 1 枚ごとに **役割** を選ぶ。
  - **景色・物**: その場所・物を出すシーンの参照。落とした画像は、まずこの役割になる。
  - **人物**: 全シーンに同じ人物として出る。**1 枚まで**(複数の出演者は扱わない)。人物の画像は、役割を選び直して人物にする(風景の画像が人物として口を合わせようとしないように)。
- **人物の説明**: 人物の画像を入れると出る。MV と同じく、空なら画像のプロンプト、無ければ画像を見て作る。画像タブの edit で作った画像(参照画像を直したもの)のプロンプトは「周囲を広げる」のような直し方の指示なので使わない(画像を見て作る)。MV タブも同じ。**🔍 画像から作る** も MV と同じ。
- **長さ(秒)**: 曲もセリフも無いときだけ出る。30 秒以上、3600 秒(1 時間)まで。既定 60 秒。
- **画角** / **画質** / **背景の文字** / **シーンの最短(秒)** / **シーンの最長(秒)** / **シード**: MV と同じ(表は「[MV(ミュージックビデオ)タブ](#mvミュージックビデオタブ)」)。字幕・テロップは描かせない(焼き込むテロップは別)。
- **最終の音声**: **自動** / **音声なし(映像だけ)**。
  - 自動: セリフがあれば読み上げ(曲は小さく混ぜ、読み上げの長さで切る。曲が短ければ繰り返さない)、曲だけなら曲、どちらも無ければ H3 の音。
  - 音声なし: 映像だけの MP4。他のツールで音を付けたい人向け。

### 画風

MV タブと同じ。**画風** を選ぶと全シーンの演出をその画風にそろえる。参照画像(人物・景色)が 1 枚でもあれば、参照の見た目を保つ形の文になる。物語の欄の下に「画風: …(生成時に指示を足します)」と出る。

### 人物とセリフの決まり

- **セリフがあって人物の画像が無い**ときは、**画面の外の声(ナレーション)** になる。「人物の画像が無いので、ナレーション(画面の外の声)として景色に載せます。口を合わせるには、役割『人物』の画像を入れてください」と出る。
  - 長さとシーンの切り方は、口を合わせるときと同じ(読み上げの長さ、文の切れ目)。
  - シーンは景色・物の画像を参照に(無ければ参照なしで)、尺を指定して音なしで作る。演出は読み上げの文に沿って景色を描き、人物は映さない。
  - 結合で読み上げを載せる(曲があれば BGM として混ぜる)。テロップ・SRT も同じように作れる。
- 人物の画像があるときは、読み上げが全編を通して流れるので、**人物が映らないシーン(景色だけ)は作れない**。

### 長さの警告

- 見込みの長さが 5 分を超えると、作る前に警告が出る(止めはしない)。例: 「5 分を超えます。A4000 の高速で 1 シーン約 3.5 分 → 約 2.3 時間」。
- セリフの長さは読み上げを作るまで決まらないので、警告は文字数からの目安。

### 作る

1. 物語を書く(または曲・セリフ・参照画像を入れる)。
2. 画角・画質・最終の音声を選ぶ。
3. **ショート動画を作る**。右上に制作の画面が出る。

中では、**音声の準備**(読み上げを作って文で分ける / 曲を分離して分ける)→ **シーン割り**(どちらも無しのときだけ)→ **演出の作成**(筋と、シーンごとの演出)→ **シーンの生成** → **結合** の順に進む。

### 制作の画面

MV タブと同じ。一時停止 / 再開 / 中止、シーンごとの **やり直す** と **プロンプトを編集**、**結合し直す**、**削除** が使える。ショート動画では、さらに:

- 上に「時間軸: セリフ / 曲 / 指定の長さ」「最終の音声」「テロップあり」が出る。
- シーンの行に、**場所**、**セリフ**(または **場面**)、使った **参照**(「1: 人物」など)が出る。セリフのシーンには **セリフ** の札。
- **結合し直す** の横に、**音声: 自動** / **音声: 音声なし** の選びと、**テロップ** の印(セリフの制作だけ)がある。変えて結合し直せる(前の動画はギャラリーに残る)。
- テロップがあるときは、最終の動画の下に **SRT** のリンクが出る。
- 完成した動画は `outputs/video/short_<ID>.mp4`(結合し直すと `_2`、`_3`…)。

### うまく作るこつ

- 物語は、場面を時間の順に短い文で並べる。「夜明けの灯台、漁師たちの帰港、市場の賑わい、夕方の海に沈む太陽」のように。
- 人物を出さないなら、物語に「人物は登場しない」と書く。
- 人物の画像は、MV と同じく **無地の背景・小物なし** を勧める。画像の夜の光やマイクは、H3 が全シーンに引き継ぐ。
- 出したくないものは物語に書く。例: 「マイクやステージは出さない」「歌わない。静かに語る」。
- 長いものほど時間がかかる。まず 30〜60 秒、高速で試す。

### 時間の目安

| GPU | 条件 | 時間 |
|---|---|---|
| RTX A4000(16GB) | 高速 | 1 シーン約 3.5 分。5 分の動画(約 40 シーン)で約 2.3 時間、10 分で約 4.7 時間 |
| RTX PRO 6000(共有、H3 の利用枠 24GiB) | 横長・標準、参照なし | 1 シーン約 55 秒。60 秒(8 シーン)で約 9 分 |

シーンの数に比例して増える。

## 編集タブ

ギャラリーの動画・画像・曲を、つなぐ・区間を切る・途中に挿入する・色を変える・境目をつなぎ替える・曲を付け替える、簡単な編集。

- **元の動画は一切変えない**(非破壊)。編集は「どのクリップのどこを、どの順で、どんな効果で」という設定だけで、ffmpeg(CPU)で作り直す。
- **GPU もエンジンの起動も要らない**。MV や動画の生成と同時に使える。
- プリセットとサンプルは無い(編集は素材ごとに違うため)。

### 編集プロジェクト

- 上の選ぶ欄で **編集プロジェクト** を選ぶ。
- **新規**: 名前を聞かれるので入れる(空なら「無題」)。
- **名前の変更** / **削除**: 選んでいるプロジェクトに。削除しても、書き出した動画と元のクリップはギャラリーに残る。
- 右下の履歴は、編集プロジェクトのカード(長さ・クリップ数)。押すと開く。× で削除。
- 最後に開いていたプロジェクトは、次に開いたときも開く。

### クリップ

- **クリップ** の欄に、動画・画像を落とす(動画タブ・MV・ショート動画の生成物、ギャラリー、PC のファイル)。**末尾に足される**。まとめて落としてもよい。
- 右下の **ギャラリー** を開き、動画・画像を **押すだけ** でも末尾に入る(曲を押すと **音声** に入る)。ギャラリーは開いたままなので、続けて選べる。編集タブでは、ギャラリーを開いてもプレビューは見えたまま。
- 各行:
  - サムネイル(押すと、その位置を再生)、名前、長さ(「4.5 秒(元 10 秒)」)。
  - 動画は **in** / **out**(元の動画のうち使う範囲。元の動画の秒)。画像は **秒数**(落としたときは 3 秒)。
  - **▲** / **▼** で並べ替え、**×** で外す(元の動画は残る)。
- 出力の寸法とコマ率は **先頭のクリップ** に合わせる(画像だけなら 1024×576・24fps)。大きさの違う動画・画像は、縮めて黒い縁を付ける。

### 区間

区間は、操作をかける範囲。**つないだだけの時間で数える**(クロスフェードで縮む前の時間)。欄の横に「全体 N 秒(つないだだけの長さ)」が出る。

- **開始** / **終了** に秒を数字で入れる(矢印キーでも動かせる。小数 3 桁まで)。
- **ここから** / **ここまで**: プレビューを再生して目的の位置で止め、押すと、その位置が開始・終了に入る。プレビューの再生位置からは、クロスフェードの分を自動で直して入れる。
- **全体**: 0 から最後まで。
- **クリア**: 開始と終了を消す(区間なし)。
- 同じ **ここから** / **ここまで** / **クリア** は、右のプレビューのすぐ下にもある。いまの区間は「区間 a〜b 秒」と出て、目盛りに青い帯で重なる。

### プレビューの下のボタン

- 再生位置(「再生位置 0:12.3 / 0:30.0(プロジェクトの 13.5 秒)」)。
- **◀ 1 コマ** / **1 コマ ▶**: 止めてから、1 コマずつ動かす。
- **ここから** / **ここまで** / **クリア**: 左の区間の欄と同じ。
- **このコマを画像に**: 止めた位置のコマを、元の動画から元の解像度の PNG にしてギャラリー(画像)に入れる。色調などの効果は掛からない。画像タブの参照や、編集の挿入にそのまま使える。プレビューができてから押す。
- 目盛り(クリップごとの帯)の上を押すと、その位置を再生する。効果の帯と境目の印も出る。

### 操作

- **区間を削除**: 開始〜終了を切り取って、前後をつなぐ。区間にかかるクリップは、その位置で分けて入れ替える。
- **位置に挿入**: 挿入の欄に動画か画像を落とし、**位置に挿入**。**開始** の位置に入る(そこにあるクリップは分かれる)。画像は **画像の秒数**(0.5〜60 秒、既定 3)で入る。

### 色調・調整

- **色調**(見た目を選ぶ): **モノクロ** / **セピア** / **暖色** / **寒色** / **フィルム風(退色)** / **周辺を暗く** / **色を反転** / **ぼかし**。
- **調整**(値を決める): **彩度**(0〜3、1 でそのまま)/ **コントラスト**(0〜3、1 でそのまま)/ **明るさ**(-1〜1、0 でそのまま)。つまみで値を決める。
- どちらも **区間に適用** か **全体に適用**。いくつでも重ねられる。

### 選択区間の効果

区間の始めから終わりにかけて効く(区間の外は元のまま)。区間が必須。**区間に適用** で付ける。

| 効果 | 動き |
|---|---|
| 黒へフェード / 黒からフェード | 区間の中で、黒へ落ちる / 黒から出る |
| 黒にする | 区間の間、真っ黒 |
| 白へフェード / 白からフェード | 白へ / 白から |
| ズームイン / ズームアウト | 倍率 1.05〜2 で、中央へ寄る / 引く |
| 右へパン / 左へパン / 下へパン / 上へパン | 倍率ぶん拡大して、見える窓を端から端へ動かす |
| ズームインしながら右へ / ズームインしながら左へ | 寄りながら横へ動く |

- ズーム・パンは、挿入した静止画を動かす(ケン・バーンズ)のに向く。倍率のつまみは、ズーム・パンを選んだときだけ出る。
- 黒縁つきで入った静止画(横長の動画に正方形の画像など)は、倍率を黒縁が消えるくらいにすると縁が見えない(横長 16:9 に正方形なら 1.75 倍以上)。
- 黒で区切りたいときは、「黒へフェード」→「黒にする」→「黒からフェード」を並べる。

### 付けた色調・調整・区間の効果

付けたものの一覧(種類・値・区間、または「全体」)。**×** で外す。区間を削除すると、効果の区間も削った分だけ詰まる。

### 境目の効果

- クリップが 2 つ以上になると、境目ごとの行(「1 → 2」)が出る。**カット** / **クロスフェード** / **黒を挟む** と、秒数(0.5〜2 秒)。
- 秒数は、**前後のクリップの短いほうの半分** までに縮められる。両方とも 1 秒以上ないと付けられない。
- **区間の境目に適用**: 選んだ効果を、選択区間の中にある境目すべてに、区間の長さ(0.5〜2 秒に丸める)で付ける。区間が境目をまたいでいないと「区間の中に境目がありません」と出る。
- 区間の削除や挿入で分けたところは、カットになる。
- クロスフェード・黒を挟むは、その秒数だけ前後が重なるので、書き出しはつないだだけの長さより短くなる。

### 先頭・末尾のフェード

**先頭フェードイン(秒)** と **末尾フェードアウト(秒)**。0 で無し。合わせて書き出しの長さまで。

### 音声

- **元の音** / **曲に差し替え** / **元の音 + 曲**(曲は -14dB で混ぜる)/ **音なし**。
- 曲は、下の欄に **音楽タブの曲・ギャラリー・PC の音声ファイル** を落とす。落とすと、元の音・音なしのときは「曲に差し替え」になる。
- 曲は先頭から使い、動画の長さで切る。曲を入れずに「曲に差し替え」を選ぶと、先に曲を落とすよう案内が出る。

### 元に戻す / やり直す

- 操作 1 回が 1 段(最大 100 段)。管理役を再起動しても戻せる。
- 戻したとき、その状態のプレビューが残っていれば、作り直さずにそれを出す。

### プレビュー

- 操作のたびに、**プレビュー**(短辺 480 の軽い MP4)を自動で作り直す。作っている間は動画がぼけて、進みが出る。
- 続けて操作すると、作りかけは中止して新しく作る。
- 「**プレビューは古い版です**」と出たら、**作り直す** を押す。

### 書き出し

- **書き出し** で、元の解像度の MP4 を作る。`outputs/video/edit_<ID>.mp4`(2 回目以降は `_2`…)。ギャラリーに載る。
- 長い動画は数分かかる(進みが出る)。プレビューとは別に走る。
- 書き出した動画は、プレビューの下の **最後に書き出した動画** で見られ、**保存** で手元に取り出せる。他のタブの入力欄へもドラッグできる。

### 細かい決まり

- 時刻は、すべて **つないだだけの時間**(境目の効果で縮む前)で数える。
- **0.1 秒未満の切れ端は作らない**。区間の削除や挿入でそれより短い端が残るときは、その端を捨てる。境目から 0.1 秒以内の挿入は、境目に寄せる。
- 編集プロジェクトが使っている動画・画像・曲は、ギャラリーから削除できない。
- やらないこと: 字幕の入力、速度の変更、ピクチャインピクチャ、音量の細かい調整、キーフレーム、マウスで引くタイムライン。

### 例: 作った動画をつないで 1 本にする

1. **新規** で「まとめ」を作る。
2. ギャラリーを開き、MV やショート動画の完成した動画を順に押す。
3. 境目を **クロスフェード** 1 秒にする。
4. **音声** を「曲に差し替え」にして、音楽タブの曲を落とす。
5. **末尾フェードアウト(秒)** を 2 にする。
6. プレビューで確かめて **書き出し**。

- いまの曲・参照画像・物語・セリフ・人物の説明は、作例のものに置き換わる。
- 素材(画像・曲)は、読み込んだときに **ギャラリーへ 1 回だけ** コピーされる(`outputs/samples/<id>/`)。もう一度読み込んでも増えない。消してから読み込み直すと、また入る。
- サンプルの動画・画像・曲は CC0(自由に使ってよい)。

### プリセット

入力欄の値(プロンプト・サイズ・秒数・STEP・モデル・ジャンルなど)に名前を付けて保存したもの。画像・動画・音楽・MV・ショート動画の各タブにある。

- 選ぶと入力欄に入る(生成はしない)。選べない値(読み込んでいないモデル、この PC に無い話者など)は入れず、「そのままにした項目」として知らせる。
- 文の欄(プロンプト・テーマ・歌詞など)は、プリセットの文が空でなければ置き換える(サイズだけのプリセットで、書きかけの文を消さない)。音楽のキャプションだけは、空でも反映する。
- 落とした素材(参照画像・フレーム・曲・キャラクター画像)と、読み上げの欄は含めない。ショート動画は、物語・セリフ・人物の説明も含めない。MV の人物の説明・曲の内容は、自分で書いた文だけを含める。

### 同梱のプリセット

| タブ | プリセット |
|---|---|
| 画像 | アニメ調イラスト / 写真風 / 水彩画 / 縦長 9:16 SNS 用 / ラフ確認用(2 ステップ)/ 高精細(6 ステップ) |
| 動画 | 縦長ショート 9:16 5 秒 / 横長 16:9 MV 風 10 秒 / 正方形 SNS 5 秒 / 軽量お試し(6GB 向け)/ 歌唱 Ref2VA + Vocal Lock |
| 音楽 | J-POP バラード / アニソン 疾走感(90 秒)/ シティポップ / Lo-fi 作業用インスト / おまかせ 切ないバラード |
| MV | YouTube 横長 16:9 標準 / YouTube 横長 16:9 高速 / TikTok・Reels 縦長 9:16 高速 / Instagram 正方形 1:1 標準 / Instagram フィード 縦 4:5 標準 / 高画質 横長 16:9(24GB 以上) |
| ショート動画 | YouTube 横長 16:9 標準 / 縦長 9:16 高速(TikTok・Reels・Shorts)/ 正方形 1:1 標準 / 映像だけ(音声なし)横長 16:9 / 長尺 3 分 横長 16:9 高速 |

同梱のものは変えられない。直したいときは、選んでから **別名で保存** で複製し、それを直す。

### 自分のプリセットを作る

1. 入力欄を好きな値にする。
2. **別名で保存** を押し、名前を入れて **OK**。同じ名前があれば「名前(2)」のように番号が付く。
3. 直したら、そのプリセットを選んだまま **保存**(上書き。確認が出る)。
4. **名前の変更** / **削除** は自分のプリセットだけ。

### 書き出しと読み込み

- **書き出し**: そのタブの自分のプリセットを JSON のファイルに保存する。
- **読み込み**: 書き出した JSON を選ぶ。別の PC に移せる。ほかのタブ用のプリセットが入っていれば、そのタブで選べる。1 件でも不正なら何も読み込まない(1 回 200 件まで)。

JSON の形:

```json
{"presets": [
  {"tab": "mv", "name": "縦長 9:16 低 VRAM", "values": {"aspect": "9:16", "quality": "low", "min_s": 5, "max_s": 7}}
]}
```

### 自分のサンプルを足す

`samples/<id>/` というフォルダを作り(`<id>` は英小文字・数字・`-`・`_`)、`sample.json` と、使うファイルを置く。管理役を起動し直すと読む。読めないもの・ファイルが足りないものは、起動時に警告を出して飛ばす。

| 項目 | 中身 |
|---|---|
| `id` | フォルダ名と同じ |
| `tab` | `image` / `video` / `music` / `mv` / `short` |
| `title` | 題(必須) |
| `description` | 説明 |
| `values` | 入力欄の値(プリセットと同じ形。ショート動画は `story` / `narration` / `character` も、MV は `character` / `concept` も入れられる) |
| `assets` | 素材の配列。各項目に `role`(`person` / `scenery` / `song`)、`kind`(画像は `image`、曲は `audio`)、`file`(フォルダの中のファイル名)、任意で `description` と `params`(画像なら `prompt`、曲なら `theme` / `caption` / `genre` / `lyrics` など) |
| `video` / `thumb` | できあがりの動画とサムネイルのファイル名(任意) |
| `made` | 作った条件のメモ(GPU・画質など、任意) |
| `license` | ライセンスの文(任意) |

同梱の `samples/mv-starry-night/sample.json` を写して直すのが早い。

## エンジンとメモリ

### エンジンの欄の見方

- **起動**: そのエンジンのプロセスを起こす。
- **停止**: 止める。外部のエンジンと、仕事中のエンジンは止められない。
- **準備**: GPU に載せて、すぐ使える状態にする(必要なら他を降ろす)。
- **ログ**: 最新 100 行を開く。同じ内容は `logs/<名前>.log`。
- **同梱 LLM** の行: 管理役が持つ LLM(llama-server)。状態(停止 / 起動中 / 準備完了(GPU)/ 準備完了(CPU))と RAM を出し、**停止** で止められる(使用中は押せない。次に LLM を使うときに自動で起動し直す)。
- **外部** の札: 管理役が起動したのではなく、すでにポートで待ち受けていたエンジン。管理役はそれをそのまま使い、止めない。外部のエンジンでは、プロンプト強化が使えないことがある(管理役から起動し直すと使える)。

### エンジン 1 つずつ(40GB 未満)と、同時に複数(40GB 以上)

| 使い方 | いつ | 動き |
|---|---|---|
| エンジン 1 つずつ(exclusive) | 総 VRAM が 40GiB 未満(既定) | GPU には 1 つだけ。別のエンジンが要ると、いまのものを降ろして載せる |
| 同時に複数(share) | 総 VRAM が 40GiB 以上(既定) | エンジンごとに利用枠を決めて、合計が収まる間は降ろさない。足りなければ、仕事中でないものを使った時刻の古い順に降ろす |

- 降ろし方: 画像・動画のエンジンは **退避**(モデルを GPU から降ろす。プロセスは残る)。音楽(ACE-Step)は降ろす方法が無いので **停止** する。
- 既定の利用枠: MiniMax-H3 = 総 VRAM の半分(最大 48GB)、MiniMax-H3-Image = 35%(最大 31GB)、ACE-Step = 14GB。`studio.local.toml` で変えられる(付録)。
- どちらにするかは `[gpu] mode` で決め打ちもできる(`exclusive` / `share` / `auto`)。
- GPU を使わない仕事(読み上げ・MV の分離・結合・編集)は、GPU の生成と並行に進む(同時に 2 つまで)。

### 順番と「GPU の空きを待っています」

- 生成はエンジンごとに並ぶ(同じエンジンは 1 つずつ)。受け付けた順に見て、始められるものから始める。
- 進みの欄の文:
  - 「順番を待っています」: 前の仕事が終わるのを待っている。
  - 「エンジンを準備しています」: エンジンの起動・載せ替え中。
  - 「GPU の空きを待っています(MiniMax-H3 が生成中)」: 別のエンジンが生成中で、それを降ろさないと載らない。終われば自動で始まる。**中止** もできる。
- 先頭が GPU の空き待ちのとき、後から来た仕事はそのエンジンに入れない(追い越され続けないように)。

### 同梱 LLM

- プロンプト強化・作詞・MV とショート動画の演出・画像から人物の説明・曲から曲の内容に使う、管理役が持つ 1 つの LLM(Gemma 4 E4B)。
- いま GPU にいるエンジンの隣の、空き VRAM に入る分だけ GPU に載せる(入らない分は CPU)。
- **GPU で生成している間に頼まれたら、CPU だけで動いて答える**(GPU の生成は止めない。遅くはなる)。だから、動画を作りながら作詞してもよい。
- GPU で生成する直前に止めて、VRAM を返す。
- 画像・音声を読む投影ファイル(約 0.56GB)は、初めて「画像から作る」「曲から作る」を使うときに取得する。

### GPU が 2 枚以上ある PC

- 管理役が VRAM を数えるのは 1 枚だけ(管理役を起動した環境の `CUDA_VISIBLE_DEVICES` の先頭、無ければ 0 番)。上の段に「使用 GPU: 0 <名前>」と出る(2 枚以上のときだけ)。
- 既定(`[gpu] devices = "auto"`)では、すべてのエンジンと同梱 LLM に `CUDA_VISIBLE_DEVICES=<その番号>` を渡して、同じ 1 枚で動かす。
- 別の GPU なら `devices = "1"` など、寄せないなら `devices = "all"` を `studio.local.toml` の `[gpu]` に書く。`[components.<名前>.env]` に `CUDA_VISIBLE_DEVICES` を書いたエンジンは、その指定のまま。

### Windows の共有 GPU メモリ

Windows は VRAM があふれると、CPU メモリを GPU のメモリの代わりに使い始める。止まりはしないが、極端に遅くなる。上に「**VRAM があふれて共有 GPU メモリに退避しています(極端に遅くなります)。**…」と出たら:

1. 画角・解像度・サイズを小さくする。
2. GPU を使う他のアプリ(ブラウザの動画再生、ゲーム、別の生成ツール)を閉じる。
3. 使用量表示の **共有 GPU メモリ** が下がるのを確かめる。

### 小さな GPU(6〜12GB)の作り方

- **1 つずつ作る**: 同じタブで続けて作ると、載せ替えが起きない。画像を全部作ってから動画、のように。
- **MV・ショート動画は画質を「低 VRAM」か「高速」に**。6GB 以下は低 VRAM(長辺 512)。
- **動画タブは 512×512 / 768×512 / 512×768**。同梱のプリセット **軽量お試し(6GB 向け)**。
- **画像タブは 1024×1024 以下**、ステップは 2〜3 で下書き。
- **音楽**: VRAM が 10GB 未満(8GB のカードなど)では、自動で省メモリの設定(2B モデルのプロファイル、言語モデルを CPU に、int8 など)が入る。STEP は 8 (Turbo) のまま。
- **同梱 LLM を CPU だけにする**: `studio.local.toml` の `[llm]` に `gpu = "off"`。VRAM の取り合いが無くなる(LLM は遅くなる)。
- **ディスクを節約する `--no-ref`**: setup に付けると、参照モード用のキャッシュ(約 32GB)を作らない。VRAM は減らない。そのかわり Ref2VA・Ref2I・Vocal Lock が使えなくなり、それを使う MV と、参照画像つきのショート動画も作れない。参照を使わない人向け。
- **CPU メモリ**: 32GB が前提。16GB では動画の準備と LLM が厳しい。他のアプリを閉じる。

## 困ったとき

### よくあること

- **「動画(MiniMax-H3) が終了していました(RAM 不足の可能性があります)。ログの最後: …」と出る**: 生成の途中でエンジンのプロセスが終わっていた(多くは RAM 不足で OS に止められた)。管理役はそのエンジンを停止扱いにし、**1 回だけ自動で起動し直してやり直す**(MV・ショート動画のシーン、画像・動画・音楽のジョブ)。2 回目も終了したら失敗にする。他のアプリを閉じてから、やり直す・再開する。
- **RAM の少ない PC(32GiB 未満)**: GPU の仕事を始める前に、待機中の AivisSpeech(管理役が起動したもの・読み上げ中でない)と同梱 LLM(使用中でない)を自動で止める(ジョブに「メモリを空けています(読み上げ・同梱 LLM を止めます)」と出る。次に使うときに起動し直す)。`[gpu] free_cpu_engines` = `"auto"`(既定)/ `"always"` / `"never"`。
- **最初の画像の生成が 1 時間以上かかる / ダウンロードが続く**(RAM が何度も埋まる): MiniMax-H3-Image の本体のキャッシュ(ステップ数ごと、約 11GB)が無く、最初の生成で bf16 の本体(約 62GB)をシャード 1 つずつ取得して量子化している(以前の setup は作らなかった)。待てば、その後は速い。先に作るなら、スタジオを止めて PowerShell で `cd <h3image のフォルダ>; .\.venv\Scripts\python.exe scripts\prepare_models.py --build-cache 3`(GPU を使う)。`.\setup.bat --only h3image` でも確かめて作れる。
- **「〇〇 の Python 環境が不完全です(モジュール uvicorn がありません)」と出る**: そのエンジンの仮想環境の導入が途中で終わっている(ログに `No module named ...` がある)。スタジオを止めてから、`.\setup.bat --only <名前>`(Linux は `./setup.sh --only <名前>`)を実行する。名前は h3 / h3image / ace など、案内の文に出ているもの。
- **エンジンが「エラー」と出る**: エンジンの欄のその行の **ログ** を開く。同じ内容は `logs\<名前>.log`(`logs/h3.log` など)。モデルが無い・環境が無いときは、setup をもう一度実行する。
- **ポートが使われている**: 8700(管理役)、8701(同梱 LLM)、8611(動画)、8633(画像)、8001(音楽)、10101(読み上げ)のどれかを、別のアプリが使っている。相手を止めるか、`studio.local.toml` でポートを変える。
- **「管理役に接続できません」と出る**: `run.bat`(`run.sh`)の画面が止まっていないか確かめる。Windows のコンソールは、中をクリックすると出力が止まる(簡易編集モード)。Enter で再開する。
- **「VRAM があふれて…」と警告が出る**: 画角(サイズ・解像度)を下げる。他の GPU アプリを閉じる。
- **「GPU の空きを待っています」のまま**: 別のエンジンが生成中。終われば自動で始まる。急ぐなら、その生成を中止する。
- **「中止」を押してもすぐ止まらない**: 中止は、いまのステップの後で止まる。音楽は、言語モデルの段と、最後のデコードの最中は止まらないことがある。
- **外部のエンジンが止まらない・強化できない**: 管理役は、自分が起動したエンジンだけを止める。外で起動したエンジン(**外部** の札)は止めない。プロンプト強化は、管理役から起動したエンジンでないと使えないことがある。いったん自分で止めて、管理役に起こさせる。
- **外部の ACE-Step が GPU にいて「同居できません」と出る**: ACE-Step は GPU から降ろせない。先に自分で止めるか、`studio.local.toml` の `[components.ace]` に別の `port` を書いて、管理役に起こさせる。
- **更新したのに画面が古いまま**: ブラウザが古い JS を持っている。`Ctrl+F5`(Mac は `Cmd+Shift+R`)で読み直す。
- **ffmpeg が見つからない**(MV・ショート動画・編集で「ffmpeg が見つかりません(PATH に入れてください)」): Windows は `winget install --id Gyan.FFmpeg -e --source winget` のあと、PowerShell と `run.bat` を開き直す。Linux は `sudo apt install ffmpeg`。
- **MV タブに「MV の音声処理の道具…が見つかりません」と出る**: タブの **道具を入れる(約 1.3GB)** ボタンを押す(進み具合がボタンの横に出る。記録は logs/mvtools-install.log)か、`.\setup.bat --only mvtools`(Linux は `./setup.sh --only mvtools`)。Demucs と librosa の入った Python がすでにあれば、`[mv] tools_python` に書けば入れなくてよい。ショート動画の「曲だけ」も同じ道具を使う。
- **「MiniMax-H3 の参照モード用のキャッシュ(transformer_ref_int8、約 32GB)がありません」と出る**(MV タブ・ショート動画タブの上と、動画タブの Ref2VA / 静止画(参照あり)にも同じ案内が出る。MV タブでは **MV を作る** が押せない): Windows と RAM 48GB 未満の PC では、エンジンが重みを量子化キャッシュのファイルから流すので、参照モード(MV、参照画像・セリフを使うショート動画、動画タブの Ref2VA / Ref2I)にこのキャッシュが要る。setup で入れたエンジンには作ってあるが、既に入れてあったエンジン(`dir` を書いた、または setup が見つけた)には無いことがある。setup を `--no-ref` で実行した人も無い(`--no-ref` が省くのが、まさにこのキャッシュ)。T2VA・FL2VA・T2I と、参照画像もセリフも無いショート動画は、無くても作れる。1 回だけ、次の手順で作る。
  1. スタジオ(管理役)を止める(`run.bat` の画面で `Ctrl+C`)。RAM を空けるため。作るのに GPU は使わない。
  2. PowerShell で `cd <h3 のフォルダ>; .\venv\Scripts\python.exe scripts\prepare_lowvram.py --ref` を実行する(Linux は `cd <h3 のフォルダ> && venv/bin/python scripts/prepare_lowvram.py --ref`)。h3 のフォルダは、`studio.local.toml` の `[components.h3]` の `dir`。書いていなければ、スタジオのフォルダの `components\minimax-h3`(例: `C:\h3-creator-studio\components\minimax-h3`)。画面の案内とエラーには、この PC 用のコマンドがそのまま出る。
  3. これは transformer_ref(66GB)をシャード 1 つずつ取得して量子化し、取得した分は消しながら、`models\prequant\transformer_ref_int8` に約 32GB を書く。ディスクの空きが約 37GB 要る。回線次第で数時間。RAM 16GB でも作れる。できているキャッシュ(本体の `transformer_int8` など)は飛ばす。途中で止めても壊れない。同じコマンドをもう一度実行すればよい(ただし、作りかけの参照モード用は最初から作り直す)。
  4. 終わったら `run.bat` でスタジオを起動し、失敗した制作の **再開** を押す。曲の分析と演出はそのまま使い、シーンだけを作り直す(作る前に断られたときは、もう一度作ればよい)。
  5. 代わりに `.\setup.bat --only h3`(Linux は `./setup.sh --only h3`)でもよい。キャッシュを確かめて「いま作りますか?」と聞き、同じコマンドを流す。
- **話者が出ない(AivisSpeech が動かない)**: 「話者を取得できません」と出たら、話者の欄を押すと読み直す(止まっていれば起動する)。直らなければ、エンジンの欄の AivisSpeech(音声合成)の行の **ログ** を見る。フォルダが壊れていれば、`components\AivisSpeech-Engine` を消して setup をもう一度。
- **テロップの字が豆腐(□)や別の字体になる(Windows)**: `studio.local.toml` に次を書いて、管理役を起動し直す。

```toml
[mv]
subtitle_font = "Meiryo"
```

- **CPU メモリが足りない**: 動画の準備(量子化)中に落ちるときは、他のアプリを閉じる。32GB 未満では、動画と同梱 LLM が厳しい。
- **MV のシーンが全部同じ部屋・同じ光になる**: キャラクター画像の背景・光が引き継がれている。無地の背景の画像で作り直す(「[画像タブ](#画像タブ)」)。
- **MV やショート動画に字幕のような文字が出る**: 字幕は出さないよう指示しているが、看板などの文字は出ることがある。**背景の文字** を **文字を出さない** にして、そのシーンを **やり直す**。
- **削除できない**: 使っている制作・編集プロジェクト・ジョブがある。理由に出た制作やプロジェクトを先に消す。

### 不具合を知らせるとき

次をそろえると、原因を追いやすい。

1. 何をしたか(タブ、押したボタン、入力の値。プリセットを **書き出し** して添えてもよい)。
2. 画面に出た文(進みの欄の「失敗: …」、エンジンの欄の「失敗: …」)。
3. `logs/` のフォルダのログ(`h3.log`、`h3image.log`、`ace.log`、`llm.log` など。該当するエンジンのもの)。
4. `run.bat`(`run.sh`)の画面に出ていた文。
5. GPU(名前と VRAM)、CPU メモリの量、Windows か Linux か。

## 付録: ファイルと API

### outputs/ の中

| 場所 | 中身 |
|---|---|
| `outputs/image/` | 画像タブの画像、動画タブの静止画、編集の「このコマを画像に」 |
| `outputs/video/` | 動画タブの動画、MV(`mv_<ID>.mp4`)、ショート動画(`short_<ID>.mp4` と SRT)、編集の書き出し(`edit_<ID>.mp4`)。結合し直し・2 回目以降の書き出しは `_2`、`_3`… |
| `outputs/audio/` | 音楽タブの曲、読み上げの声 |
| `outputs/uploads/` | PC から取り込んだファイル |
| `outputs/mv/<ID>/` | MV の制作の作業ファイル(シーンのクリップ、分離したボーカルなど) |
| `outputs/short/<ID>/` | ショート動画の制作の作業ファイル |
| `outputs/edit/<ID>/` | 編集のプレビュー |
| `outputs/samples/<id>/` | 読み込んだサンプルの素材 |
| `outputs/thumbs/` | サムネイル |
| `outputs/studio.db` | 台帳(生成物・ジョブ・制作・プリセットの記録) |

ファイルを直接消すと、ギャラリーと合わなくなる。消すときは画面の削除を使う。

### studio.local.toml の主な項目

`studio.toml` が既定。自分の PC の設定は `studio.local.toml` に書く(書いた項目だけが上書きされる。見本は `studio.local.toml.example`)。変えたら管理役を起動し直す。

| 項目 | 意味 |
|---|---|
| `host` / `port` | 管理役の待ち受け。既定 `127.0.0.1` / `8700` |
| `components_dir` | エンジンを取り込む場所。既定 `components` |
| `[components.<名前>]` の `dir` | エンジンの場所を直接指す(名前は `h3` / `h3image` / `ace` / `aivis`) |
| 同 `enabled` | `false` でそのエンジンを使わない |
| 同 `port` | エンジンのポート |
| 同 `vram_budget_gb` | 同時に複数のときの、そのエンジンの利用枠(GB) |
| `[components.<名前>.env]` | エンジンに渡す環境変数 |
| `[gpu]` の `mode` | `auto`(既定)/ `exclusive`(1 つずつ)/ `share`(同時に複数) |
| `[llm]` の `port` | 同梱 LLM のポート(既定 8701) |
| `[llm]` の `gpu` | `auto`(空きに入る分だけ GPU)/ `off`(CPU のみ)/ `all` / 層数 |
| `[llm]` の `gguf` / `llama_server` / `mmproj` / `tools_dir` | LLM のファイルを自分で指すとき / 取得先のフォルダ |
| `[mv]` の `tools_python` | MV・ショート動画の音声処理の Python(空なら `components/mvtools/.venv`) |
| `[mv]` の `device` | ボーカル分離の装置。空なら CPU(`cuda` で GPU) |
| `[mv]` の `subtitle_font` | テロップの字体。空なら Noto Sans CJK JP |

### 主な API(スクリプトから使う人向け)

管理役は `http://127.0.0.1:8700` の JSON の API で、画面も同じものを使う。生成はジョブ(投げて、状態を読みに行く)。

| 呼び方 | すること |
|---|---|
| `GET /api/status` | VRAM・CPU メモリ・エンジンの状態・レーン |
| `POST /api/components/{名前}/start` ・ `stop` ・ `ensure` | エンジンの起動・停止・準備 |
| `GET /api/components/{名前}/log` | エンジンのログ |
| `POST /api/jobs` | 画像・動画・音楽のジョブを入れる。`{"tab", "kind", "params"}` |
| `GET /api/jobs/{id}` ・ `POST /api/jobs/{id}/cancel` | ジョブの状態・中止 |
| `GET /api/gallery` ・ `POST /api/gallery/delete` | 生成物の一覧・削除(`{"ids": [...]}`) |
| `POST /api/uploads` | ファイルの取り込み(フォームの `files`) |
| `POST /api/enhance` | プロンプト強化(`{"tab", "text"}`) |
| `GET /api/tts/speakers` ・ `POST /api/tts` | 話者の一覧・読み上げ(`{"text", "style_id", "speed"}`) |
| `POST /api/music/theme` ・ `lyrics` ・ `caption` | テーマ・歌詞・キャプションを作る |
| `GET /api/mv` ・ `POST /api/mv` ・ `GET /api/mv/{id}` | MV の制作の一覧・作成・詳細 |
| `POST /api/mv/{id}/pause` ・ `resume` ・ `cancel` ・ `reassemble` | 一時停止・再開・中止・結合し直す |
| `POST /api/mv/{id}/scenes/{番号}/retry` | シーンのやり直し(`{"prompt", "seed"}`) |
| `/api/short/...` | ショート動画(MV と同じ形) |
| `/api/edit/...` | 編集プロジェクト(state・undo・redo・preview・export・frame) |
| `GET /api/presets?tab=` ・ `POST /api/presets/import` ・ `GET /api/presets/export?tab=` | プリセット |
| `GET /api/samples?tab=` ・ `POST /api/samples/{id}/load` | サンプル |

`kind` は `h3image.t2i` / `h3image.edit` / `h3.t2va` / `h3.fl2va` / `h3.ref2va` / `h3.t2i` / `h3.ref2i` / `ace.simple` / `ace.omakase`。MV・ショート動画・編集のジョブは `/api/jobs` からは入れられない(それぞれの API を使う)。

例: 画像を 1 枚作る。

```bash
curl -s -X POST http://127.0.0.1:8700/api/jobs -H "Content-Type: application/json" \
  -d '{"tab": "image", "kind": "h3image.t2i", "params": {"prompt": "白い無地の背景の少女、アニメ調", "width": 1024, "height": 1024}}'
# 返ってきた id で状態を見る
curl -s http://127.0.0.1:8700/api/jobs/<id>
```

できた生成物は、`GET /api/gallery` の `url`(`/outputs/...`)から取り出せる。
